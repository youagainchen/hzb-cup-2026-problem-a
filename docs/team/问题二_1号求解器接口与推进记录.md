## 等待2号的最小交接包

1. Q2实例对象或构造函数，客户编号必须与距离矩阵索引一致。
2. 在 `src.model.q2_adapter`（或协商后的模块）提供 `build_context(data_dir: Path) -> Question2Context`，内部包装单一评分入口 `score = evaluate_solution(routes, ...)`。
3. 返回值至少包含：
   - `total_cost: float`
   - `policy_violation_count: int`
   - `is_feasible: bool` 或 `feasible: bool`（建议提供）
   - 若提供 `feasibility: dict[str, bool]`，1号求解器会要求全部为真。
4. 一组违规为0的确定性基线路线，包含车型、物理车号、趟次号和发车时刻。
5. 明确8:00、16:00端点是否计入限行，以及政策按到达时刻还是服务开始时刻判定。

交接完成后的正式命令：

```powershell
run_question2.cmd --adapter src.model.q2_adapter:build_context
```
